# retail-sales-analytics
Portfolio project for retail sales data analysis using SQL and Python.

# Overview
This project analyzes retail transaction data using SQL and Python to identify sales trends, product performance, and customer purchasing patterns.

# Objectives
- Analyze monthly sales trends.
- Identify top-performing products and countries.
- Examine customer purchasing behavior.
- Develop business recommendations based on data.

# Tools
- SQL
- Python
- pandas
- Matplotlib
- Jupyter Notebook

# Analysis Plan
1. Inspect and clean the dataset.
2. Calculate sales metrics using SQL.
3. Perform exploratory data analysis using Python.
4. Visualize key findings.
5. Summarize business implications and recommendations.
